# مفاجأة عيد ميلاد رزان

صفحة احتفالية عربية متجاوبة صُممت كهدية عيد ميلاد خاصة لرزان من زيرو (يوسف). تبدأ بهدية مغلقة، ثم تكشف عن الرسالة، المؤثرات الاحتفالية، عدّاد العمر المباشر، ولحن اختياري.

## التقنيات

- HTML وCSS وJavaScript في ملف واحد
- خطوط Cairo وGreat Vibes من Google Fonts
- Web Audio API للحن المدمج
- استضافة ثابتة على Netlify

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح، أو شغّل أي خادم ملفات ثابتة من مجلد المشروع. لا توجد تبعيات أو خطوة بناء.
